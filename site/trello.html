Valor de negocio
Protege la integridad de los registros del almacén y permite auditar quién hizo cada operación.

Como integrante del personal de almacén, quiero iniciar sesión con mis credenciales y acceder únicamente a las funciones que corresponden a mi perfil, para proteger la información de la empresa y saber que mis operaciones quedan registradas a mi nombre.

Criterios de aceptación · 3 de 3
  • Hecho Dado que el usuario ingresa credenciales válidas, cuando presiona "Ingresar", entonces el sistema redirige al panel principal de inventario.
  • Hecho Dado que el usuario ingresa una contraseña incorrecta o un usuario inexistente, cuando intenta ingresar, entonces se muestra un mensaje de error claro sin revelar cuál dato falló.
  • Hecho Dado que los campos están vacíos, cuando intenta enviar el formulario, entonces el sistema bloquea el envío y solicita completar los datos obligatorios.
Tareas técnicas · 4 de 4
  • Hecho Crear la tabla de usuarios con sus credenciales de acceso.
  • Hecho Validar las credenciales en el servidor y mostrar un mensaje de error que no revele cuál dato falló.
  • Hecho Definir los roles de acceso y restringir las funciones según el perfil.
  • Hecho Registrar qué usuario realiza cada operación.

Tiempo estimado

Prioridad
Alta
Valor de negocio
Elimina la duplicidad de códigos de producto, que es la causa principal del desfase entre stock físico y registrado.

Como encargado de almacén, quiero registrar nuevos productos indicando código SKU, nombre, categoría, unidad de medida y stock mínimo, para mantener un catálogo maestro ordenado y estandarizado antes de registrar movimientos.

Criterios de aceptación · 3 de 3
  • Hecho Dado que se registra un producto con un código SKU ya existente, cuando se intenta guardar, entonces el sistema rechaza el registro e indica que el código está duplicado.
  • Hecho Dado que todos los campos obligatorios están completos y el stock mínimo es mayor o igual a cero, cuando se guarda el producto, entonces aparece inmediatamente en la tabla del catálogo.
  • Hecho Dado que el usuario ingresa valores negativos en el stock inicial o mínimo, cuando intenta guardar, entonces el sistema muestra una validación impidiendo números negativos.
Tareas técnicas · 6 de 6
  • Hecho Crear el formulario de registro con SKU, nombre, categoría, unidad de medida y stock mínimo.
  • Hecho Validar que el código SKU no esté duplicado antes de guardar.
  • Hecho Impedir valores negativos en el stock inicial y en el stock mínimo.
  • Hecho Mostrar los mensajes de error sin romper el diseño del formulario.
  • Hecho Definir el umbral de stock mínimo por producto.
  • Hecho Mostrar el producto registrado en la tabla del catálogo.

Valor de negocio
Automatiza el Kardex y evita el despacho de mercadería inexistente.

Como encargado de almacén, quiero registrar movimientos de entrada (compras/devoluciones) y salida (despachos/consumo) asociados a un producto, para actualizar el stock disponible automáticamente y conservar un historial trazable.

Criterios de aceptación · 3 de 3
  • Hecho Dado que se registra una entrada de X unidades, cuando se confirma la operación, entonces el stock actual del producto se incrementa exactamente en X unidades y se guarda la fecha, hora y usuario responsable.
  • Hecho Dado que se registra una Salida mayor al stock disponible actual, cuando se intenta confirmar, entonces el sistema bloquea la operación con el mensaje "Stock insuficiente".
  • Hecho Dado que se registra una Salida válida, cuando se confirma, entonces se descuenta del stock actual y queda registrado en el historial de movimientos.
Tareas técnicas · 5 de 5
  • Hecho Crear la tabla movimientos_inventario con tipo, cantidad, fecha, hora y usuario.
  • Hecho Alinear los nombres de los campos del formulario con las columnas de movimientos_inventario.
  • Hecho Actualizar el saldo de la tabla productos en cada entrada o salida.
  • Hecho Implementar la validación de stock insuficiente en salidas.
  • Hecho Verificar la validación de stock insuficiente en salidas.

Anticipa los quiebres de stock que detienen el despacho y obligan a compras de emergencia.

Como supervisor de operaciones, quiero identificar de inmediato los productos cuyo stock actual sea igual o inferior al stock mínimo configurado, para gestionar órdenes de reposición a tiempo y evitar el desabastecimiento.

Criterios de aceptación · 2 de 2
  • Hecho Dado que un producto tiene stock_actual <= stock_minimo, cuando se visualiza el listado de inventario, entonces la fila o estado se resalta con una etiqueta roja ("Stock Crítico").
  • Hecho Dado que se registra una entrada que eleva el stock por encima del mínimo, cuando se actualiza la vista, entonces la alerta desaparece y pasa a estado normal ("Disponible").
Tareas técnicas · 5 de 5
  • Hecho Comparar el stock actual con el stock mínimo configurado de cada producto.
  • Hecho Resaltar con la etiqueta roja "Stock Crítico" los productos en nivel crítico.
  • Hecho Mostrar el estado "Disponible" cuando una entrada supera el mínimo.
  • Hecho Definir si la alerta se calcula en la consulta o se guarda en la tabla de productos, y registrar la decisión.
  • Hecho Verificar ambos criterios con datos de prueba.
